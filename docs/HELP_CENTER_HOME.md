## Frequently Asked Questions

**Q: Can I use PEN2PRO with my Starter tier account?**
A: Yes! Starter tier includes blueprint creation and management. To run AI agents, upgrade to Pro or Elite.

**Q: How long does an agent take to run?**
A: Typically 2-3 minutes. The AI analyzes your business idea and generates strategic recommendations.

**Q: Can I run multiple agents on the same blueprint?**
A: Yes! You can run Blueprint Agent, SEO Agent, and all future agents on the same blueprint. Results display separately.

**Q: What if an agent fails?**
A: You'll see an error message. Refresh the page and try again. If it persists, check the troubleshooting guide.

**Q: When will [feature X] be available?**
A: Check the [Feature Roadmap](./HELP_FEATURE_ROADMAP.md) for estimated timelines.

**Q: Is my data secure?**
A: Yes. We use industry-standard encryption, JWT authentication, and MongoDB security best practices.

**Q: Can I export my blueprint results?**
A: Currently: view and copy from the page. Soon: PDF/Word export, email sharing, integrations.
